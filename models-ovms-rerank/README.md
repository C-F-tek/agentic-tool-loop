# OVMS Reranker

`models-ovms-rerank/` contains the OpenVINO Model Server (OVMS) reranker setup for the BAAI/bge-reranker-v2-m3 model.

## Architecture

OVMS requires **OpenVINO IR format** (`.xml` + `.bin`) — not raw ONNX or PyTorch models. The conversion is done by `export_model.py` from the OVMS demos repository.

### Flow

```
HuggingFace (PyTorch) → export_model.py rerank_ov → OpenVINO IR (.xml/.bin) → OVMS (port 3550)
```

### Directory Structure

```
models-ovms-rerank/
├── export_model.py          ← Downloaded from OVMS demos (auto-generated)
├── requirements_export.txt  ← Dependencies for openvino venv
├── models/                  ← Generated by export_model.py
│   ├── config.json          ← OVMS config (auto-generated)
│   └── BAAI/
│       └── bge-reranker-v2-m3/
│           ├── openvino_model.xml      ← OpenVINO IR model (~1GB fp16, ~2GB fp32)
│           ├── openvino_model.bin
│           ├── openvino_tokenizer.xml  ← OpenVINO tokenizer
│           ├── openvino_tokenizer.bin
│           ├── graph.pbtxt             ← Model graph definition
│           ├── tokenizer.json          ← HuggingFace tokenizer
│           ├── tokenizer_config.json
│           ├── sentencepiece.bpe.model
│           └── special_tokens_map.json
└── config_ovms.json        ← Legacy (deprecated — use models/config.json)
```

## Usage

### Prerequisites

- Python 3.14 in `venvs\openvino`
- OpenVINO 2026.2.1 installed in the venv
- GPU or CPU available

### Launch Reranker

```powershell
# Activate the openvino virtual environment first
venvs\openvino\Scripts\Activate.ps1

# Run the launcher script (downloads export_model.py if missing, converts model, starts OVMS)
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\CarmineFaiola\AI\services\ovms-reranker-npu.ps1"
```

The reranker will be available on:
- **REST API**: `http://127.0.0.1:3550`
- **Health check**: `curl http://127.0.0.1:3550/v2/models/BAAI%2Fbge-reranker-v2-m3/ready`
- **Rerank endpoint**: `curl -X POST http://127.0.0.1:3550/v3/rerank -H "Content-Type: application/json" -d '{"model": "BAAI/bge-reranker-v2-m3", "query": "hello", "documents":["welcome","farewell"]}'`

### Manual Conversion (one-time setup)

```powershell
venvs\openvino\Scripts\Activate.ps1
cd C:\Users\CarmineFaiola\AI\models-ovms-rerank

# Download export script if not present
curl https://raw.githubusercontent.com/openvinotoolkit/model_server/refs/heads/main/demos/common/export_models/export_model.py -o export_model.py

# Convert model to OpenVINO IR (GPU uses int8, CPU uses fp16)
python export_model.py rerank_ov --source_model BAAI/bge-reranker-v2-m3 --weight-format int8 --target_device GPU --config_file_path models/config.json --model_repository_path models

# Start OVMS
& "C:\Users\CarmineFaiola\AI\ovms-runtime\ovms\ovms.exe" --rest_port 3550 --rest_bind_address 127.0.0.1 --config_path models\config.json
```

## Configuration

| Parameter | Value | Description |
|---|---|---|
| `OVMS_RERANK_MODELS` | `C:\Users\CarmineFaiola\AI\models-ovms-rerank` | Models repository root |
| `OPENVINO_PROVIDER_DEVICE` | `GPU.0` or `CPU` | Target device for inference |
| `OVMS_REST_PORT` | `3550` | REST API port |
| Model | `BAAI/bge-reranker-v2-m3` | Cohere-compatible reranker |
| Weight format | `int8` (GPU) / `fp16` (CPU) | Quantization level |

## Troubleshooting

### "Configuration file is not a valid JSON"

The old `config_ovms.json` format is deprecated. Use `models/config.json` generated by `export_model.py`.

### "Directory does not exist: .../bge-reranker-v2-m3\bge-reranker-v2-m3"

This was caused by OVMS `--add_to_config` generating incorrect `base_path`. The new flow uses `export_model.py rerank_ov` which generates the correct config automatically.

### "No version found for model in path"

OVMS requires versioned directories (`1/`, `2/`, etc.) for model versions. The `export_model.py rerank_ov` command creates the correct structure automatically.

### UTF-8 BOM issues

OVMS 2026.2 C++ parser cannot handle UTF-8 BOM in config files. The `export_model.py` script writes clean ASCII/UTF-8 without BOM.
