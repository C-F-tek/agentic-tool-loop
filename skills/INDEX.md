## Come Usare le Skills

Ogni skill e' un modulo di conoscenza che Cline puo referenziare durante il lavoro.

### Workflow

```
Task → Identificare skill → Leggere skill → Eseguire workflow → Verificare risultato
```

## Principi Comuni

Tutte le skills seguono il metodo forense AICarmine:

```
Symptom → Evidence → Confirmed cause → Minimal fix → Verification
```

## MCP Tools Authoritative

Tutte le skills usano gli strumenti MCP esposti come autoritativi. Non inventare strumenti.
