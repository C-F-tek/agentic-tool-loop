# npu-models

Local model store for OpenVINO/NPU assets.

The launcher contract expects the Phi sidecar model at:

```text
C:\Users\carmi\AI\npu-models\Phi-3.5-mini-instruct-int4-cw-ov
```

Model binaries, tokenizer files, Hugging Face download metadata and compiled
blob/cache files are local runtime artifacts and are intentionally ignored by
Git.
