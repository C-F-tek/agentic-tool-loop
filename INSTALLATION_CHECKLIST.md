## Known Issues Resolved

| Issue | Root Cause | Fix |
|---|---|---|
| "Configuration file is not a valid JSON" | UTF-8 BOM in config file | Use export_model.py which writes clean UTF-8 without BOM |
| "Directory does not exist: .../bge-reranker-v2-m3\bge-reranker-v2-m3" | OVMS --add_to_config generates wrong base_path | Use export_model.py rerank_ov instead |
| "No version found for model in path" | OVMS requires versioned directories | export_model.py creates correct structure |
| "The file is not valid json" | Raw ONNX/PyTorch models not supported | Convert to OpenVINO IR first |
| openvino==2026.3.0rc1 not found | RC version unavailable for Python 3.14 | Use openvino==2026.2.1 |
| openvino-tokenizers==2026.3.0.0rc1 not found | RC version unavailable for Python 3.14 | Use openvino-tokenizers==2026.2.1.0 |
| kokoro==0.9.4 not found | Version requires Python <3.13 | Remove from requirements |
