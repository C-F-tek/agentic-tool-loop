# Symbol Comprehension Improvements

This directory contains tools and references that enable immediate MCP symbol comprehension without thinking overhead.

## Overview

The following improvements have been implemented to help the AI agent understand and resolve MCP tools immediately:

1. **Symbol Quick Reference Generator** - Structured tool metadata reference (117 tools, 14 servers)
2. **Compact Routing Table** - Intent-to-tool mapping for immediate resolution
3. **Pre-Tool Call Symbol Injector** - Hook that injects tool context before execution (compact mode)
4. **Runtime Tool Discovery Cache** - Local cache with keyword indexing
5. **Symbol Resolution Assistant** - Task-to-tool pattern matching (70+ patterns)

## Files

### `tool_symbol_reference.json`

Machine-readable symbol reference generated by `generate_symbol_reference.py`. Contains:

- `tool_entries`: Full metadata for each tool (name, category, description, read_only, confirmation_gate, related_tools)
- `category_index`: Tools grouped by category
- `family_summary`: Statistics by tool family
- `write_gated_tools`: List of tools requiring confirmation
- `confirmation_gates`: Mapping of tool names to their confirmation gate arguments

**Schema**: `aicarmine_tool_symbol_reference.v1`
**Size**: ~30KB (117 tools)

### `mcp_routing_table.json`

Compact intent-to-tool routing table for immediate symbol resolution. Uses pipe-separated intent patterns mapped to server+tool pairs.

**Schema**: `aicarmine_mcp_routing_table.v1`
**Size**: ~8KB
**Usage**: Primary lookup for tool resolution during pre-tool injection

### `generate_symbol_reference.py`

Generator script that scans MCP server files and produces `tool_symbol_reference.json`.

**Usage**:
```bash
python tools/generate_symbol_reference.py
```

**Output**: `.docs/tool_symbol_reference.json`

**Extraction patterns**:
1. `ToolSpec` registration (authoritative)
2. Docstring tool lists
3. `TOOL_NAMES` arrays
4. JSON schema definitions
5. Function definitions

### `services/codex_bridge/tool_surface_cache.py`

Runtime tool discovery cache with keyword indexing. Maintains a local cache of the MCP tool surface discovered at runtime.

**Functions**:
- `load_tool_surface_cache()`: Load cache (returns None if expired)
- `save_tool_surface_cache(server_tools)`: Save tool surface with keyword index
- `get_cached_tool_by_name(tool_name)`: Get specific tool from cache
- `resolve_tool_by_query(query, top_k=3)`: Keyword-based tool resolution
- `get_tools_by_category(category)`: Get tools in a category
- `get_category_index()`: Get category-to-tools mapping
- `is_cache_fresh()`: Check if cache is valid
- `invalidate_cache()`: Remove cache file

**TTL**: 10 minutes (configurable via `CACHE_TTL_SECONDS`)

### `tools/symbol_resolution_assistant.py`

Task-to-tool pattern matching assistant with 70+ patterns covering all 117 tools.

**Usage as module**:
```python
from tools.symbol_resolution_assistant import resolve_tool_for_task

result = resolve_tool_for_task("leggi il contenuto di config.py")
# Returns: {"recommended_tool": "aicarmine_repo_read", "confidence": 0.95, ...}
```

**Usage as CLI**:
```bash
python tools/symbol_resolution_assistant.py "leggi il contenuto di config.py"
```

### `.clinerules/hooks/lib/aicarmine_pretool_symbol_injector.ps1`

PowerShell hook library that injects structured tool context into the prompt before tool execution. Uses compact routing table for minimal token overhead.

**Function**: `Get-AICarminePreToolSymbolInjection`

**Integration**: Used by `.clinerules/hooks/PreToolUse.ps1`

## How It Works

### Pre-Tool Call Flow

1. User sends task/request to Cline
2. Cline prepares to call an MCP tool
3. **PreToolUse hook** fires:
   a. `aicarmine_cline_contract_probe.ps1` - Validates contract
   b. `aicarmine_cline_pretool_observer.ps1` - Existing observer logic
   c. **NEW**: `aicarmine_pretool_symbol_injector.ps1` - Injects compact tool context
4. Tool is called with enhanced context in prompt

### Injected Context Format (Compact)

```
TOOL_CONTEXT:
  name: aicarmine_repo_read
  server: aicarmine-codex-app
  category: repo/read
  params: path, max_chars
  read_only: True
```

### Symbol Resolution Hierarchy

1. **Pattern matching** (`symbol_resolution_assistant.py`) - 70+ Italian/English patterns
2. **Routing table lookup** (`mcp_routing_table.json`) - Intent-to-tool mapping
3. **Keyword scoring** (`tool_surface_cache.py`) - Lightweight query matching
4. **Symbol reference** (`tool_symbol_reference.json`) - Full metadata lookup

## Maintenance

### Regenerating Symbol Reference

```bash
python tools/generate_symbol_reference.py
```

### Updating Tool Patterns

Edit `tools/symbol_resolution_assistant.py` and add new patterns to `TASK_PATTERNS`.

### Updating Routing Table

Edit `.docs/mcp_routing_table.json` and add new intent patterns.

### Cache Management

The tool surface cache expires after 10 minutes. To force refresh:

```python
from services.codex_bridge.tool_surface_cache import invalidate_cache
invalidate_cache()
```
