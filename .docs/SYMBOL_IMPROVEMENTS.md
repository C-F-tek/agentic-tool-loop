# Symbol Comprehension Improvements

This directory contains tools and references that enable immediate MCP symbol comprehension without thinking overhead.

## Overview

The following improvements have been implemented to help the AI agent understand and resolve MCP tools immediately:

1. **Symbol Quick Reference Generator** - Structured tool metadata reference
2. **Pre-Tool Call Symbol Injector** - Hook that injects tool context before execution
3. **Runtime Tool Discovery Cache** - Local cache of discovered tool surface
4. **Symbol Resolution Assistant** - Task-to-tool pattern matching

## Files

### `tool_symbol_reference.json`

Machine-readable symbol reference generated by `generate_symbol_reference.py`. Contains:

- `tool_entries`: Full metadata for each tool (name, category, description, read_only, confirmation_gate, related_tools)
- `category_index`: Tools grouped by category
- `family_summary`: Statistics by tool family
- `write_gated_tools`: List of tools requiring confirmation
- `confirmation_gates`: Mapping of tool names to their confirmation gate arguments

**Schema**: `aicarmine_tool_symbol_reference.v1`

### `generate_symbol_reference.py`

Generator script that scans MCP server files and produces `tool_symbol_reference.json`.

**Usage**:
```bash
python tools/generate_symbol_reference.py
```

**Output**: `.docs/tool_symbol_reference.json`

### `services/codex_bridge/tool_surface_cache.py`

Runtime tool discovery cache module. Maintains a local cache of the MCP tool surface discovered at runtime.

**Functions**:
- `load_tool_surface_cache()`: Load cache (returns None if expired)
- `save_tool_surface_cache(server_tools)`: Save tool surface to cache
- `get_cached_tool_by_name(tool_name)`: Get specific tool from cache
- `get_tools_by_category(category)`: Get tools in a category
- `is_cache_fresh()`: Check if cache is valid
- `invalidate_cache()`: Remove cache file

**TTL**: 5 minutes (configurable via `CACHE_TTL_SECONDS`)

### `tools/symbol_resolution_assistant.py`

Task-to-tool pattern matching assistant. Helps resolve which MCP tool to use based on task description.

**Usage as module**:
```python
from tools.symbol_resolution_assistant import resolve_tool_for_task

result = resolve_tool_for_task("leggi il contenuto di config.py")
# Returns: {"recommended_tool": "aicarmine_repo_read", "confidence": 0.95, ...}
```

**Usage as CLI**:
```bash
python tools/symbol_resolution_assistant.py "leggi il contenuto di config.py"
```

### `.clinerules/hooks/lib/aicarmine_pretool_symbol_injector.ps1`

PowerShell hook library that injects structured tool context into the prompt before tool execution.

**Function**: `Get-AICarminePreToolSymbolInjection`

**Integration**: Used by `.clinerules/hooks/PreToolUse.ps1`

## How It Works

### Pre-Tool Call Flow

1. User sends task/request to Cline
2. Cline prepares to call an MCP tool
3. **PreToolUse hook** fires:
   a. `aicarmine_cline_contract_probe.ps1` - Validates contract
   b. `aicarmine_cline_pretool_observer.ps1` - Existing observer logic
   c. **NEW**: `aicarmine_pretool_symbol_injector.ps1` - Injects tool context
4. Tool is called with enhanced context in prompt

### Injected Context Format

```
TOOL_CONTEXT:
  name: aicarmine_repo_read
  category: repo/read
  description: Read one or more file contents with character limit
  read_only: True
  common_params: path, max_chars
  related_tools: aicarmine_repo_list_files, aicarmine_repo_search
```

## Maintenance

### Regenerating Symbol Reference

```bash
python tools/generate_symbol_reference.py
```

### Updating Tool Patterns

Edit `tools/symbol_resolution_assistant.py` and add new patterns to `TASK_PATTERNS`.

### Cache Management

The tool surface cache expires after 5 minutes. To force refresh:

```python
from services.codex_bridge.tool_surface_cache import invalidate_cache
invalidate_cache()
```
